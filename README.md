# Code Orbit To-Do List CLI App

## Project Description
The To-Do List CLI App is a simple Python application that helps users manage their daily tasks through a command-line interface.

## Features
- Add new tasks
- View all tasks in a numbered list
- Remove tasks by task number
- Handle invalid inputs
- Simple menu-driven interface

## Technologies Used
- Python 3
- Lists
- Functions
- Loops
- Conditional Statements
- Exception Handling

## Setup Instructions
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python todo_list.py`

## How to Use
1. Choose `1` to add a task.
2. Choose `2` to view all tasks.
3. Choose `3` to remove a task.
4. Choose `4` to exit the application.

## Data Storage
Tasks are stored in a Python list while the program is running. They are not saved permanently.
